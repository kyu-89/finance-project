# Sprint 3 — 예산·월 결산

기준: PRD §6.1~6.6, §7.1~7.3, §23.9.

## 완료 조건

- 카테고리별 1~12월 소비 예산을 연간 표에서 저장한다.
- 전년도 예산 복사와 전년도 posted 실적 기반 초안을 생성한다.
- 월간관리에서 예산/실적/잔액/소진율과 70·90·100% 경고를 텍스트로 표시한다.
- 월 결산에서 수입·소비·저축·차액·저축률·소비율을 posted 거래만으로 계산한다.
- 모든 예산은 household owner RLS 및 카테고리 tenant 일관성을 DB가 보장한다.

## 순서

1. budgets migration/RLS/tenant trigger
2. 예산·결산 순수 계산과 경계 테스트
3. 연간 예산 편집/전년도 복사/실적 초안 서버 액션
4. 설정 예산 UI 및 월간 예산·결산 탭
5. 통합 테스트, Supabase/Vercel 배포, HANDOFF 갱신
