## 5. 아직 하지 않은 작업

### 5.1 Excel import preview 재검증

사용자가 “어제도 했다”고 하여 이번 세션에서는 생략했다. 원본 파일은 다음 위치다.

```text
C:\Users\미니쉬테크놀로지-김규남\Desktop\dev\personal-finance\2026년 (1).xlsm
```

필요하면 `/settings/data`의 **월별 거래 전체 가져오기**에서 파일을 선택하고 preview의 전체 건수/가져오기 가능 건수/오류 건수를 확인한다. 실제 가져오기 버튼은 누르지 않는다.

### 5.2 UI patch

사용자가 `git apply ui-improvemtent.patch`를 나중에 직접 처리하기로 했다. 현재 해당 patch 파일은 작업공간에서 발견되지 않았다. 파일이 전달되면 먼저 `git apply --check`로 적용 가능 여부를 확인한 뒤 적용한다.

### 5.3 GitHub push 관련 참고

GitHub Device Code 인증을 완료했고, 다음 push는 성공했다.

```text
10be653..0c9f4d3  main -> main
```

인증 문제 재발 시 Git Credential Manager를 사용한다. 사용자 프로필의 Git 설정은 Windows `schannel` 문제 때문에 OpenSSL 백엔드로 변경되어 있다.

```powershell
git config --global http.sslBackend openssl
```

토큰, 비밀번호, `service_role` 키는 채팅이나 문서에 기록하지 않는다.
