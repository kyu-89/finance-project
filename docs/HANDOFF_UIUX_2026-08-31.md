# 재무 대시보드 UI/UX 개편 인수인계

## 현재 반영 범위

- 홈 대시보드: 모바일 헤더 우선 배치, 기간 필터 접이식 처리, 월·가구 필터 축소
- 모바일 LNB: 메뉴명 단순화(`홈 / 입력 / 추가 / 자산 / 설정`), 추가 버튼 크기 조정
- 월간 관리: 거래 입력과 전체 거래 검색을 한 영역으로 통합, 예산 핵심 KPI 상단 배치
- 월간 거래표: 컬럼 Grid 폭 통일, 예정 거래 액션 영역 줄바꿈 및 폭 조정
- 상태 문구: `확정` 대신 `실제 반영됨`, `건너뜀` 대신 `이번 회차 제외`
- 필수 필드 라벨: 우측 상단 표시 규칙 통일
- 거래 상세: 경조사·정부지원금 섹션 조건부 노출
- CSS: 미정의 yellow 토큰 추가, 월간 행 `content-visibility` 렌더링 오류 수정, Tailwind 기본 유틸리티 오버라이드 제거
- 배포 화면에서 확인된 월간 처리 컬럼 우측 밀림을 3열 입력 + 전체 폭 버튼으로 재배치
- 계좌 해지·카드 해지·예적금 중도해지·보험 해지·기타자산 처분·반복항목 종료·거래 삭제 전 확인 대화상자 추가
- 전체 거래 표를 모바일에서 카드형 행으로 전환해 금액과 상태가 화면 안에 표시되도록 조정
- 공통 확인 버튼을 도입해 계좌·카드·예적금·기타자산의 종료/처분 액션을 확인 후 실행하도록 변경
- 설정 > 데이터 관리는 기본 거래 파일 업로드·내보내기만 먼저 보여주고, 나머지 금융 데이터 가져오기는 ‘고급 가져오기 및 복구’로 접어 정보 과밀을 줄임

## 검증 결과

- `npx tsc --noEmit`: 성공
- `npm run lint`: 오류·경고 없음
- `git diff --check`: 성공
- `npm test`: 테스트 파일 탐색 결과 없음
- `npm run build`: 컴파일 성공 후 Supabase 환경변수 미설정으로 페이지 데이터 수집 단계 중단

## 남은 우선 작업

1. 모바일·데스크톱 전 라우트 실배포 캡처 회귀 테스트
2. 대출 대환 처리 등 금융상품 상태 변경에도 확인 모달 공통화
3. 투자·대출·리포트·전체 거래 표의 모바일 카드화
4. `Badge`, `Amount`, `ConfirmButton`, `FormField`, `TableCard` 공통 컴포넌트 도입
5. 상태 변경 되돌리기 및 변경 이력 제공
6. 드릴다운(상위 카드 → 카테고리 → 거래) 실제 클릭 검증

## 최근 추가 변경

- 전체 거래 표 모바일 카드화
- 월간 상태 배지 설명 툴팁 추가
- 모바일 대시보드 기간 필터를 접이식으로 전환
- 홈 헤더를 필터보다 먼저 배치
- 설정 데이터 관리의 가져오기 메뉴를 기본/고급 영역으로 재구성
- 미사용 레거시 폼과 변수 정리

## 적용 방법

```bash
git apply --check ui-improvements.patch
git apply ui-improvements.patch
npx tsc --noEmit
npm run lint
npm run build
```

이미 일부 변경이 적용된 브랜치라면 먼저 `git diff`로 중복 적용 여부를 확인한다.
